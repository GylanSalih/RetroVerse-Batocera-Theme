## About The Project

This repository contains a custom theme designed specifically for Batocera, RetroBat, and EmulationStation. The theme enhances the user interface by offering a modern, sleek, and intuitive design tailored for retro gaming enthusiasts.

<p align="right">
  <a href="#readme-top">
    <img src="https://img.shields.io/badge/Back%20to%20top-000000?style=for-the-badge&logo=upptime&logoColor=white" alt="Back to top">
  </a>
</p>

## Features

- **Dynamic Game Metadata Display**: 
  Separate windows for game details, including images, videos, descriptions, and publisher information, with a start button for direct game launching.

- **Optimized Layout**: 
  Gridless format focusing on detailed game information instead of cluttered grids.

- **Customizable Visuals**: 
  A highly customizable design to match individual preferences, featuring adjustable backgrounds, colors, and font styles.

- **Compatibility**: 
  Fully compatible with Batocera, RetroBat, and other EmulationStation-based frontends.

## Installation

1. Download the theme files from this repository.
2. Copy the theme folder to the theme directory of your Batocera, RetroBat, or EmulationStation setup.
   - Example path: `~/.emulationstation/themes/`
3. Open your system settings and select the theme from the theme options.
